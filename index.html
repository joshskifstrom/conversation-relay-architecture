Current State: Production Inbound via Daily

sequenceDiagram
    autonumber
    participant C as Caller (PSTN)
    participant T as Twilio (Bot Flow Account)
    participant GW as Bot Flow Gateway
    participant Q as Orkes Task Queue
    participant D as Daily (WebRTC Room)
    participant M as Bot Flow Agent / Library (GKE)
    participant V as Vertex AI (Gemini Live S2S)

    C->>T: Inbound call (PSTN leg #1)
    T->>GW: Incoming call webhook
    Note over T: Caller hears ~2 buffered rings
    GW->>Q: Drop task (CallSid)
    Q->>M: Worker picks up task
    M->>D: Create Daily room
    M->>T: Connect CallSid to Daily room (SIP/PSTN leg #2)
    T->>D: Caller audio bridged into room
    M->>D: Bot joins room (WebRTC leg #3)
    loop Every turn
        D->>M: Caller audio (re-encoded, ~8 kHz)
        M->>V: Raw audio over WebSocket
        V->>M: Audio response
        M->>D: Bot audio
        D->>T: Mixed audio back to caller
        T->>C: Audio
    end
    M->>T: Transfer to human (new outbound leg #4)
    M->>M: Post-call eval: transcribe, summarize, redact

Target State: Direct via ConversationRelay

sequenceDiagram
    autonumber
    participant C as Caller (PSTN)
    participant T as Twilio (Bot Flow Account)
    participant CR as ConversationRelay<br/>(STT · TTS · Turn Detection)
    participant M as Bot Flow Agent / Library (GKE)
    participant V as Vertex AI (Gemini text)
    participant CI as Orchestrator + Conversation Intelligence

    C->>T: Inbound call (PSTN leg #1, HD audio where supported)
    T->>M: Incoming call webhook (via Bot Flow Gateway)
    M-->>T: TwiML <Connect><ConversationRelay url="wss://bot-flow">
    T->>CR: Start relay session
    CR->>M: WebSocket "setup" (CallSid, From, custom params)
    loop Every turn
        C->>CR: Caller speech
        CR->>M: "prompt" (final transcript text)
        M->>V: Text + context
        V-->>M: Streamed tokens
        M-->>CR: "text" tokens (streamed)
        CR->>C: TTS audio (11 Labs / Google / Amazon)
        CR-)CI: Live transcript to operators
        CI-)M: Webhook: sentiment / custom operator result
    end
    M->>CR: "end" with handoffData (transfer to human)
    T->>C: Dial agent on the same call (no conference room)
